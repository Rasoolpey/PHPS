## 1. Statement in the source

Definitions (§1):

$$\mathcal F_R = \{F = F^\top : F_{ij} = 0 \text{ unless } i \in R \text{ and } j \in R\},
\qquad K_R(A) = \{v : (Av)_R = 0\}, \qquad \rho(v) = v^\top H_{\rm fix}\, A\, v.$$

> **Lemma 1 (support).** Let $A$ and $H_{\rm fix}$ be fixed and $R$ given. For every
> $F \in \mathcal F_R$ and every $v \in K_R(A)$, $v^\top(A^\top F + FA)\,v = 0$.
>
> Consequently, if some $v \in K_R(A)$ has $\rho(v) > 0$, then for every $F \in \mathcal F_R$ the
> matrix $P = H_{\rm fix} + F$ satisfies $v^\top(A^\top P + PA)v = 2\rho(v) > 0$. Hence
> $-(A^\top P + PA)$ is not positive semidefinite, and no such $P$ satisfies
> $-(A^\top P + PA) \succeq 2\mu P$ for any $\mu$ with $2\mu P \succeq 0$, at any condition number.

L1 is the first sentence. L2 is the "Consequently" part.

## 2. Domain and hypotheses

- Finite index set `n` (any `Fintype`), real entries.
- `A : Matrix n n ℝ` is arbitrary: no symmetry, stability or nonsingularity is assumed.
- `R : Set n` is arbitrary, including `∅` and the full set.
- `F ∈ 𝓕_R`: `Fᵀ = F` and `F i j ≠ 0 → i ∈ R ∧ j ∈ R`.
- `v ∈ K_R(A)`: `(A *ᵥ v) j = 0` for every `j ∈ R`.
- For L2: `H_fix` is symmetric, and `ρ(v) > 0`. For the last clause: `μ ∈ ℝ` with `2μP ⪰ 0`.
- `P = H_fix + F` is **not** assumed positive definite (source, Remark 1).

**Hypothesis the source leaves implicit.** The identity `vᵀ(AᵀP + PA)v = 2ρ(v)` needs
`H_fix` to be symmetric. Without it the left side is `vᵀ(H + Hᵀ)Av`, which differs from `2vᵀHAv` in general.
The source satisfies this by construction: `H_fix` is a block-diagonal Hessian (§1), and the
source already calls `ρ` "half of `vᵀ(AᵀH_fix + H_fix A)v`", which presumes it. The Lean
statement makes it the explicit hypothesis `hH : Hᵀ = H`.

## 4. Lean statements and how they map

| Lean name | Source content | Relation |
|---|---|---|
| `SupportedOn R F`, `kerOn A R`, `witnessRate H A v` | support of `𝓕_R`, `K_R(A)`, `ρ(v)` | Definitions; `𝓕_R` is `Fᵀ = F ∧ SupportedOn R F` |
| `support_lemma_col` | `vᵀ F A v = 0` | **Stronger:** only column support (`F i j ≠ 0 → j ∈ R`), no symmetry |
| `rate_form_of_symm` | `vᵀ(AᵀP + PA)v = 2 vᵀPAv` for `Pᵀ = P` | Helper identity used throughout §1–§2 |
| `support_lemma` | L1 exactly as stated | Same hypotheses as the source |
| `rate_eq_two_witnessRate` | `vᵀ(AᵀP + PA)v = 2ρ(v)` | Adds the implicit `Hᵀ = H` (§2) |
| `not_posSemidef_neg_rate` | `−(AᵀP + PA)` is not PSD | Also gives the explicit witness `vᵀ(−(AᵀP + PA))v < 0` |
| `no_decay_rate` | no `μ` with `2μP ⪰ 0` gives `−(AᵀP + PA) ⪰ 2μP` | Same hypotheses; `⪰` is mathlib's `PosSemidef` of the difference |

**Why the column form is a strengthening, not a change of claim.** Every `F ∈ 𝓕_R` satisfies
the column-support hypothesis (`F i j ≠ 0 → j ∈ R` is the second half of `i ∈ R ∧ j ∈ R`), so
`support_lemma_col` applies to every matrix the source allows, and to non-symmetric ones as well.
The source's §2 Remark 3 already notes that only `vᵀF(Av) = 0` is used.

**Positive semidefinite in mathlib.** `Matrix.PosSemidef M` means `M` is Hermitian *and* its
quadratic form is nonnegative. "Not PSD" in that sense would also hold for a non-symmetric
matrix, so `not_posSemidef_neg_rate` also states the negative quadratic form directly. That is the
content of the source's claim, and it does not depend on how symmetry enters the definition. Here
`−(AᵀP + PA)` is symmetric anyway.

**"At any condition number"** is informal; it is covered by the fact that nothing is assumed about
`P` beyond symmetry.

## 5. Refuter pass

Done inline before formalising (2026-10-05). It found no defect in L1. For L2 it found one gap: the symmetry of `H_fix` is used but not stated (recorded in §2 above).

- L1: `vᵀ(AᵀF + FA)v = (Av)ᵀFv + vᵀFAv = 2vᵀF(Av)` uses `Fᵀ = F`; then each term
  `v_i F_ij (Av)_j` vanishes. Edge cases: `R = ∅` forces `F = 0`; `R` = everything forces `Av = 0`.
- L2, last clause: if both `−(AᵀP + PA) − 2μP ⪰ 0` and `2μP ⪰ 0`, their sum `−(AᵀP + PA) ⪰ 0`,
  which contradicts the witness. Correct as stated. It says nothing about `μ` with `2μP ⋡ 0`. That case is outside the claim, and the source does not claim it.
- The column-support form was refuted independently in the tool comparison (task T7,
  `docs/proof_tools/bakeoff/results/D_refuter.md`): verdict TRUE, no defects.

An independent refuter agent was **not** run on the full L1 + L2 statement. Ask for one if the
claim is to be cited as reviewed.
