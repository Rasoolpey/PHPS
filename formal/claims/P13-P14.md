## P14: Proposition 2 (brushless exciter)

| Lean | Statement | Hypotheses |
|---|---|---|
| `brushless_identity` | `g T_E (K_E + S_E) x · x' = P_reg - g V_FE² - P_tr` | `T_E ≠ 0` |
| `brushless_W_hasDerivAt` | `W' = g T_E (K_E + S_E(x)) x` | `S_E` continuous |
| `brushless_balance` | `d/dt W(x(t)) = (P_reg - P_tr) - g V_FE²` along the field circuit `T_E x' = V_R - V_FE` | as above |
| `brushless_W_nonneg` | `W(x) ≥ 0` | `x ≥ 0` (the model's domain), `g T_E ≥ 0`, `K_E + S_E ≥ 0` on `[0, x]` |
| `brushless_loss_nonneg` | `g V_FE² ≥ 0` | `g ≥ 0` |

Definitions for the paper: `W(x_E) = g T_E ∫₀^{x_E} (K_E + S_E(s)) s ds`, `V_FE = (K_E + S_E(x_E)) x_E + K_D I_FD`,
`g` the field circuit's power per unit of `V_R²`; the net power received through the shaft and the generator's field
is `P_sh - P_dc = P_reg - P_tr` (the model's definition of the shaft power, §5).
**The code guarantees the hypotheses:** `PHBrushlessExciter` refuses `K_E ≤ 0`, `T_E ≤ 0`, a negative saturation
constant and `g ≤ 0`; `S_E = A e^{Bx} ≥ 0` is continuous, so `K_E + S_E > 0` everywhere.
